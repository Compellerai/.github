# Compellerai/.github

The org profile and the default community health files for [Compeller.ai](https://github.com/Compellerai) repositories.

| Path | What it is |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The profile shown on the org page |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default bug report and feature request forms, and the issue chooser config |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default pull request template |

## How the defaults apply

- GitHub uses a file here for any repo in the org that does not have its own file of that type.
- A repo with anything in its own `.github/ISSUE_TEMPLATE/` folder uses none of the issue forms here.
- Licenses are not shared. Each repo keeps its own `LICENSE`.

A change here shows up across every repo in the org, so keep these files short and general. Repo-specific guidance belongs in that repo.
