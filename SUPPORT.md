# Support

| You need | Go to |
| --- | --- |
| A question or how-to | The Discussions tab of the relevant repo where it is enabled, otherwise an issue there |
| A bug report or feature request | An issue on the relevant repo |
| To report a vulnerability | [SECURITY.md](SECURITY.md). Never a public issue |
| Help with the hosted Compeller service or MCP server | info@compeller.ai |
| Anything else | info@compeller.ai |

Notes:

- Issues on `compeller-mcp` are for its docs and metadata only. Problems with the hosted service go to info@compeller.ai.
- Live demos are on Kick: https://kick.com/compeller
- Do not post secrets, license keys, or API tokens in issues or discussions.
