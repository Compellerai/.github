# Compeller.ai 👋

Compeller.ai builds tools for artists, operators, and creative teams who want AI to feel useful, controllable, and production-ready.

We are focused on practical creative infrastructure: generation workflows, media automation, live visuals, and systems that help people move from idea to output faster.

## Projects

### [REACT](https://github.com/Compellerai/react)

Native macOS app in Rust (egui, OpenGL/Metal). Real-time audio-reactive visuals, lighting (DMX via OSC/OLA, Philips Hue, WLED), NDI output, and YouTube/Twitch streaming for musicians, DJs, and venues. Apache-2.0.

### Libraries and docs

- [prodjlink-rs](https://github.com/Compellerai/prodjlink-rs): Rust client for monitoring Pioneer/AlphaTheta Pro DJ Link networks. MIT.
- [ola-rs](https://github.com/Compellerai/ola-rs): Rust RPC client for the Open Lighting Architecture. MIT.
- [link-bpm](https://github.com/Compellerai/link-bpm): unofficial clean-room Rust crate that reads the BPM from an Ableton Link session. MIT or Apache-2.0.
- [compeller-mcp](https://github.com/Compellerai/compeller-mcp): docs and metadata for the hosted Compeller MCP server at https://compeller.ai/api/mcp. No application source.

## What we build

- Creative AI tools for music, video, and visual production
- Workflow automation for artists and teams
- Real-time visual and performance systems
- Reliable infrastructure around AI-generated media

## Our approach

We care about speed, control, and quality. The best tools should stay out of the way, make hard creative work easier, and give operators enough visibility to trust what is happening.
